# Pit Safety Checklist

> [!warning] Before every match
> Safety glasses on for everyone in the pit. No exceptions.

## Battery handling

| Step | Check |
|---|---|
| Inspect terminals | No exposed copper |
| Charge state | Above 12.5 V |
| Mount | Strap secured |

## Tools
- Put tools back in the labeled bin.
- Report broken tools to a [[2-areas/team-operations/README|team lead]].
